# KATA JavaScript

Ce dépôt regroupe plusieurs exercices réalisés dans le cadre de ma formation de QA Tester afin de développer mes compétences en JavaScript.

## Objectifs

- Comprendre la syntaxe de base du langage JavaScript
- Manipuler les variables, conditions et boucles
- Utiliser les fonctions
- Travailler avec les tableaux et les objets
- Développer la logique nécessaire à l’automatisation des tests

## Contenu

Le dépôt contient plusieurs exercices progressifs, classés de `exercice1.js` à `exercice10.js`.

## Compétences développées

- JavaScript
- Logique algorithmique
- Résolution de problèmes
- Préparation à l’automatisation des tests avec Cypress et Playwright
